# Windows: запуск Mashup Lab

Лаунчер предназначен для Windows 10/11 с Windows PowerShell 5.1. Он запускается
обычными правами, без администратора. Нужен Python **3.11 или новее** с модулем
`venv` и pip; для первоначальной установки пакетов нужен интернет. Доступность
колёс зависимостей зависит от версии Python и платформы. Установите Python с
[python.org](https://www.python.org/downloads/windows/), разрешив установку
Python Launcher (`py`) или добавление Python в PATH. Перезапустите лаунчер.

1. Скачайте и распакуйте весь репозиторий, не один BAT-файл. Дважды щёлкните
   `Mashup-Lab.bat`. Можно запустить и из другого рабочего каталога.
2. Выберите **2**, чтобы создать `.venv` внутри репозитория и установить
   базовые зависимости, PySide6, FFmpeg и анализаторы из `requirements-gui.txt`. Глобальная
   установка не используется. Базовые зависимости повторно устанавливаются только
   при необходимости; интерфейс и FFmpeg проверяются после установки. Пункт **1**
   отдельно проверяет базовую среду, PySide6 и запуск FFmpeg и подсказывает,
   что делать при отсутствии компонента.
3. Подготовьте `project.yaml` по [описанию формата](project-format-specification.md),
   указав реальные пути, SHA-256 и метаданные исходных WAV. Пункты **3** и **4**
   проверяют проект и показывают план в консоли. Пустой ввод отменяет действие.
4. Выберите **5**, введите путь к проекту и имя **нового** выходного WAV. Пути
   могут быть абсолютными; относительные отсчитываются от каталога репозитория.
   Имя в кавычках при копировании из проводника допустимо. Результат находится
   по указанному пути; родительская папка должна существовать. Существующие файлы
   не перезаписываются даже после подтверждения: выберите новое имя. SHA-256 PCM,
   пиковый уровень и масштаб выводятся в консоль, но manifest пока не создаётся.
5. **6** открывает эту инструкцию, **7** завершает работу. Чтобы использовать
   графический интерфейс, запустите `Start-Mashup-Lab.bat` из папки проекта. Пункт **8** отдельно
   устанавливает или восстанавливает PySide6 и FFmpeg (через imageio-ffmpeg). Подробнее: [интерфейс и трасса](desktop-interface.md).

Экспериментальный рендер принимает только обычные PCM WAV 48 кГц, моно или
стерео, с исходной разрядностью 16/24/32 бита. `duration_ratio` должен быть 1,
`pitch_semitones` — 0: ресемплинга, растяжения и изменения высоты пока нет.
Выход — стерео PCM 16/24 бита. Рендер хранит данные в памяти; используйте
небольшие проекты. Сравнение хешей повторных запусков относится к одинаковому
окружению, а не гарантирует идентичность между разными компьютерами.

## Если что-то пошло не так

- **Python не найден или слишком старый:** установите поддерживаемую версию и
  перезапустите окно. Проверьте, что `py` или `python` доступны в PATH.
- **Ошибка установки:** проверьте соединение, права записи в каталог репозитория
  и текст pip. Пункт 2 можно повторить. Прокси и корпоративные ограничения могут
  потребовать отдельной настройки. Лаунчер не удаляет повреждённую `.venv`;
  после диагностики пользователь может самостоятельно убрать её и повторить.
- **Ошибка CLI:** проверьте путь, содержимое проекта, хеш и параметры WAV. Текст
  Python и код ошибки остаются видимыми. Пустой ответ отменяет ввод, а не рендер.
- **Кириллица отображается неверно:** используйте современный Windows Terminal
  или стандартную консоль с шрифтом, содержащим кириллицу. Лаунчер включает UTF-8
  для консольного ввода/вывода и Python на время своей работы; глобальные настройки
  не меняются. Проверка на конкретной русскоязычной системе всё равно необходима.
- **Файл результата существует:** укажите другое имя. Исходники и проект никогда
  не должны использоваться как путь результата.

Лаунчер выполняет локальный код репозитория и установку пакетов через pip;
используйте только доверенную копию проекта. Он не является защитной песочницей.

## Проверка совместимости

Автоматизированный workflow `.github/workflows/windows-launcher.yml` запускает
BAT на Windows Server runner: первый запуск, ошибка установки, повторная проверка,
отсутствие Python, неподходящий Python 3.10, Unicode/пробелы/спецсимволы в
путях, другой рабочий каталог, ошибки CLI и рендер. Эти тесты используют
перенаправленный ввод и **не заменяют** проверку визуального отображения,
клавиатурного ввода и запуска двойным щелчком на русскоязычной Windows 10/11.

Для такой ручной проверки распакуйте репозиторий в путь с кириллицей, пробелами,
`%`, `!`, `&` и скобками. Запустите BAT двойным щелчком, подготовьте окружение,
повторно запустите пункт 2, проверьте и отрендерьте проект с кириллическими
путями. Убедитесь в читаемости сообщений, корректности WAV, отказе при ошибочном
проекте и при существующем выходном файле. Повторите запуск из другой папки и
с отменой ввода. Запишите версию Windows, кодовую страницу/терминал, версию
Python и результаты. Фактическая ручная проверка русскоязычной Windows 10/11
для этой реализации пока не проведена.

Если GUI установлен до добавления конвертации, повторите пункт **8** в существующем
окружении, затем запустите `Start-Mashup-Lab.bat`. Конвертация создаёт отдельный 48 kHz
16-bit WAV; подробности и условия распространения FFmpeg — в
[руководстве GUI](desktop-interface.md).

## Общая проверка перед запуском

`Start-Mashup-Lab.bat` проверяет текущие требования из `requirements-gui.txt`
и включённых файлов, версии по маркерам платформы/Python, `pip check`, импорт
приложения и запуск FFmpeg. При ошибке он не запускает интерфейс и предлагает
диагностический `Mashup-Lab.bat`; автоматически пакеты не устанавливаются.
Новые Python-зависимости добавляются в requirements и проверяются без изменения
списка проверок; для новых внешних программ или иных возможностей нужен отдельный
probe в `mashup/environment_check.py`. Синтаксис requirements ограничен обычными
пакетами, ограничениями версий, маркерами, `-r` и прямыми архивами
с проверяемым SHA-256; неподдерживаемые директивы
приводят к ошибке проверки, а не игнорируются. Проверка не является гарантией
работы всех возможностей или визуального интерфейса.

## Установка разделения дорожек

Выберите **9** в диагностическом `Mashup-Lab.bat`. Нужен установленный Python
3.12 x64 с `py` launcher; существующее окружение GUI (включая Python 3.14)
остаётся отдельно. Движок и его зависимости устанавливаются в `.venv-separation`,
веса и параметры скачиваются в папку пользователя и проверяются по SHA-256.
Для загрузки нужен интернет и достаточно места (установка может занять несколько
гигабайт). При ошибке смотрите вывод и повторите 9. При повреждённой модели
повторная установка заменяет только файлы кэша модели, не аудио пользователя.
Открывайте интерфейс через `Start-Mashup-Lab.bat`; базовые возможности работают
и без необязательного движка.
